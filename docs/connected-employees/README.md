# מי עדיין מחובר — פאנל לתחתית הדשבורד

חבילה מוכנה להטמעה. נכתבה בסשן מרוחק (ענן), **להרצה והשלמה בסשן מקומי על EYAL**.

## למה זה לא הותקן מרחוק

הסשן המרוחק לא רואה את קבצי הדשבורד (הם ב‑Dropbox על EYAL), והגישה ל‑
`checkin.timewatch.co.il` חסומה ב‑egress proxy של הסביבה. לכן החבילה כאן — הקוד
כתוב ונבדק, וההטמעה נעשית מקומית.

## מה בפנים

| קובץ | תפקיד |
|------|-------|
| `timewatch-client.js` | לוגין ל‑TimeWatch + זיהוי מי נכנס ולא יצא היום |
| `timewatch-client.test.js` | 10 בדיקות לפרסר — `node timewatch-client.test.js` |
| `server-endpoint.js` | ראוט `GET /api/connected-employees` עם cache |
| `panel.html` | כרטיס הדשבורד עצמו (HTML+CSS+JS, RTL, עצמאי) |
| `config.example.json` | תבנית לקובץ הסודות |

## איך זה עובד

אין API רשמי של TimeWatch. הקוד נשען על שתי נקודות קצה שאומתו מפרויקטי קוד פתוח:

- `POST /punch/punch2.php` — שדות `comp`, `name`, `pw` ← עוגיית סשן
- `GET /punch/editwh.php?ee=<עובד>&e=<חברה>&y=<שנה>&m=<חודש>` — טבלת החודש

לכל עובד נמשכת שורת היום. **כניסה בלי יציאה = עדיין מחובר.**

> לא לבלבל עם הכרטיס הקיים **"מי מחובר להתראות"** — הוא heartbeat של מערכת
> ההתראות (חי/נפל), לא נוכחות. הכרטיס הזה הוא כרטיס נוסף לידו.

הכל HTTP טהור — **בלי puppeteer ובלי חלון דפדפן**, כך שאין חלונות להשאיר פתוחים.
אפס תלויות npm, Node 24 בלבד.

## דברים שכבר טופלו

- **עמודת סה״כ שעות** נראית בדיוק כמו שעון (`8:31`) ועלולה להיקרא כשעת יציאה.
  הפרסר מזהה את מיקום העמודות מתוך ימים סגורים באותו חודש ואז קורא את שורת
  היום לפי המיקום — לא לפי סדר ההופעה. יש override בקונפיג (`timeCells`).
- **קידוד עברית** — TimeWatch מגיש `windows-1255`; הקוד קורא charset מה‑header
  ומפענח בהתאם.
- **סודות** — נקראים מ‑`C:\OfficeSecrets\timewatch.json` בלבד. לא בקוד, לא ב‑Dropbox.
- **הדפדפן לא מקבל סיסמאות** — רק שמות ושעות.
- **שמות עובדים מוזרקים כ‑`textContent`**, לא כ‑HTML.

## התקנה בסשן המקומי

1. `copy config.example.json C:\OfficeSecrets\timewatch.json` ומלא חברה / מספר
   עובד אדמין / סיסמה, ואת מספרי העובדים בפועל.
2. העתק את `timewatch-client.js` ו‑`server-endpoint.js` לתיקיית הדשבורד.
3. בשרת הדשבורד:
   ```js
   const { registerConnectedEmployees } = require('./connected-employees/server-endpoint');
   registerConnectedEmployees(app);
   ```
4. הדבק את תוכן `panel.html` בשורת הכרטיסים התחתונה של
   `Y:\Dropbox\מערכות\2026\שותפות א.א.ר\dashboard.html`, ליד הכרטיס
   "מי מחובר להתראות".
5. פתח את הדשבורד דרך ה‑URL (לא `file://` — שובר קישורים).

## מה חייב אימות מקומי (הדבר היחיד שלא ניתן לבדוק מרחוק)

הרץ פעם אחת מול החשבון האמיתי:

```
node -e "require('./timewatch-client').getConnectedEmployees().then(r=>console.log(JSON.stringify(r,null,2)))"
```

ובדוק:

- **הלוגין עובר** — אם לא, ודא שמספר העובד הוא של משתמש אדמין שרואה את כל העובדים.
- **מספרי העובדים** ב‑config תואמים ל‑TimeWatch (לא לשמות המשתמש בדומיין).
- **שעות הכניסה נכונות.** אם היציאה מוצגת שגוי — פתח `editwh.php` בדפדפן, ספור
  באיזו עמודה יושבות הכניסה והיציאה, והוסף לקונפיג `"timeCells": [כניסה, יציאה]`
  (אינדקסים של תאי‑שעה בשורה, מ‑0).

## אחרי ההטמעה — לפי כללי המשרד

- [ ] המערכת מופיעה בדשבורד הראשי
- [ ] `registry.json` + `.systems-registry.json` המקומי עודכנו
- [ ] מצגת + מדריך של הדשבורד עודכנו
- [ ] לוגו המשרד על הדשבורד
- [ ] גיבוי `.bak-<תאריך>` לקובץ הדשבורד לפני העריכה
- [ ] אין סשן Claude אחר / מכונה אחרת שעובדים על אותו קובץ
- [ ] `C:\OfficeSecrets\timewatch.json` **לא** נכנס ל‑git ולא ל‑Dropbox

## הערה על עומס

10 עובדים = לוגין אחד + 10 בקשות, במקביל, עם cache של 60 שניות בשרת. גם אם
הדשבורד פתוח על 10 עמדות, TimeWatch נקרא לכל היותר פעם בדקה.
