# מי מחובר עכשיו (טיים ווטץ׳) — כרטיס לדשבורד + התראות

חבילה להטמעה בדשבורד המשרדי. נכתבה בסשן מרוחק, **להרצה והשלמה בסשן מקומי על EYAL**.

מטרה: לדעת מתי אפשר לפנות לעובד — בפרט ברינה שעובדת מבני ברק.

## למה זה לא הותקן מרחוק

הסשן המרוחק לא רואה את `dashboard.html` (Dropbox על EYAL), ו‑`a.timewatch.co.il`
חסום ב‑egress proxy של הסביבה. הקוד כתוב ונבדק; ההטמעה מקומית.

## המערכת שלך

הפורטל הוא **`a.timewatch.co.il`** (פורטל מעסיק), לא `checkin.timewatch.co.il`
(פורטל עובד). דף הנוכחות הוא `update.php`.

מבנה שורה בטבלה, משמאל לימין ב‑DOM (הדף מוצג RTL):

```
תאריך | סוג יום | שם יום | שעות תקן | כניסה1 | יציאה1 | כניסה2 | יציאה2 | כניסה3 | יציאה3 | סיבת העדרות | הערות | סה"כ
```

**עד שלושה זוגות כניסה/יציאה ביום.** מי שיצא וחזר — הזוג האחרון פתוח.
**מחובר = יש זוג עם כניסה בלי יציאה.**

## דברים שכבר טופלו

- **שעות תקן (`9:06`) וסה״כ (`8:19`) נראים כמו שעון.** הכניסות/יציאות נקראות
  לפי מיקום העמודה יחסית לתא התאריך, לא לפי "השעות שבשורה".
- **הפסקות.** קורא זוג יחיד היה מסמן חזרה מהפסקה כ"יצא להיום".
- **קידוד** — TimeWatch מגיש `windows-1255`; ה‑charset נקרא מה‑header.
- **התראה חוזרת** — אירוע נורה רק על *שינוי*, ורק פעם אחת.
- **הפעלה מחדש באמצע היום** לא מפוצצת אותך בהתראות: מי שכבר בפנים מסומן
  `initial` ולא כ"נכנס".
- **קריאה כושלת ≠ כולם יצאו** — רק קריאה מוצלחת מזיזה את מצב ה‑watcher.
- **סודות** — רק מ‑`C:\OfficeSecrets\timewatch.json`. לא בקוד, לא ב‑Dropbox.
- **הדפדפן לא מקבל סיסמאות** — רק שמות ושעות.

## ⚠️ מה חייב לכידה מקומית — לפני הכל

**נקודות הקצה של הלוגין וקריאת הנוכחות לא אומתו מול החשבון שלך.** ה‑parsing
של הטבלה מכוסה בבדיקות; מה שצריך לאמת זה איך *מגיעים* לדף.

בכרום, מחובר לטיים ווטץ׳:

1. F12 ← לשונית **Network**
2. התחבר מחדש, ואז טען את דף הנוכחות של עובד כלשהו
3. על בקשת הלוגין: **Copy → Copy as cURL** — משם `loginPath` ושמות השדות
4. על בקשת `update.php`: העתק את ה‑URL המלא — משם `attendancePath` ופרמטרי השאילתה

אם השמות שונים ממה שבקונפיג — עדכן. ואז:

```
node -e "require('./timewatch-client').getConnectedEmployees().then(r=>console.log(JSON.stringify(r,null,2)))"
```

בדוק ש‑`connected` תואם למי שבאמת בפנים, ושמספרי העובדים ב‑config הם המספרים
בטיים ווטץ׳ (מס' עובד, כמו 43) — לא שמות המשתמש בדומיין.

## התקנה

1. `copy config.example.json C:\OfficeSecrets\timewatch.json` ומלא פרטים.
2. העתק את קבצי ה‑js לתיקיית הדשבורד.
3. בשרת הדשבורד:
   ```js
   const { registerConnectedEmployees } = require('./connected-employees/server-endpoint');
   registerConnectedEmployees(app, {
     watchNames: ['ברינה'],
     pollSeconds: 120,          // התראה גם כשהדשבורד סגור
     notify: (event) => { /* ראה למטה */ },
   });
   ```
4. הדבק את `panel.html` בתוך הקטע **"בקרת שרת (פרטי)" 🔒** של `dashboard.html`
   — שם כבר יש הפרדה לתכנים שלך בלבד, כמו שביקשת.
5. פתח את הדשבורד דרך ה‑URL (לא `file://`).

## ההתראה

`notify` מקבל `{type:'in'|'out', name, since, at}` ונקרא רק על שינוי, ורק
עבור מי שב‑`watchNames`. חיבור למערכת ההתראות הקיימת, למשל דרך תור קבצים:

```js
notify: (e) => {
  const text = e.type === 'in'
    ? `${e.name} נכנסה — מ־${e.since}`
    : `${e.name} יצאה`;
  fs.writeFileSync(
    path.join('C:\\notif-requests', `presence-${Date.now()}.json`),
    JSON.stringify({ title: 'נוכחות', text }), 'utf8');
}
```
