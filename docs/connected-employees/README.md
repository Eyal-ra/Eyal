## למה זה לא הותקן מרחוק

הסשן המרוחק לא רואה את `dashboard.html` (Dropbox על EYAL), ו‑`a.timewatch.co.il`
חסום ב‑egress proxy של הסביבה. הקוד כתוב ונבדק; ההטמעה מקומית.

## המערכת שלך

הפורטל הוא **`a.timewatch.co.il`** (פורטל מעסיק), לא `checkin.timewatch.co.il`
(פורטל עובד). הלוגין ב-`/user/login.php`, דף הנוכחות ב-`/update.php`.

הלוגין הוא **שלושה שדות**: מספר חברה, שם משתמש (אימייל), סיסמה.

**שמות השדות ב-HTML לא מנוחשים.** הקוד מושך את דף הלוגין, מאתר את הטופס שמכיל
שדה סיסמה, וקורא ממנו את השמות — כולל שדות נסתרים (טוקנים) שצריך להחזיר.
ניחוש שגוי נראה בדיוק כמו סיסמה שגויה; קריאת הטופס מבטלת את הבלבול הזה.

מבנה שורה בטבלת הנוכחות, משמאל לימין ב‑DOM (הדף מוצג RTL):

```
תאריך | סוג יום | שם יום | שעות תקן | כניסה1 | יציאה1 | כניסה2 | יציאה2 | כניסה3 | יציאה3 | סיבת העדרות | הערות | סה"כ
```

**עד שלושה זוגות כניסה/יציאה ביום.** מי שיצא וחזר — הזוג האחרון פתוח.
**מחובר = יש זוג עם כניסה בלי יציאה.**

## דברים שכבר טופלו

- **שעות תקן (`9:06`) וסה״כ (`8:19`) נראים כמו שעון.** הכניסות/יציאות נקראות
  לפי מיקום העמודה יחסית לתא התאריך, לא לפי "השעות שבשורה".
- **הפסקות.** קורא זוג יחיד היה מסמן חזרה מהפסקה כ"יצא להיום".
- **קידוד** — TimeWatch מגיש `windows-1255`; ה‑charset נקרא מה‑header.
- **התראה חוזרת** — אירוע נורה רק על *שינוי*, ורק פעם אחת.
- **הפעלה מחדש באמצע היום** לא מפוצצת אותך בהתראות: מי שכבר בפנים מסומן
  `initial` ולא כ"נכנס".
- **קריאה כושלת ≠ כולם יצאו** — רק קריאה מוצלחת מזיזה את מצב ה‑watcher.
- **סודות** — רק מ‑`C:\OfficeSecrets\timewatch.env`. לא בקוד, לא ב‑Dropbox, לא בצ'אט.
- **הדפדפן לא מקבל סיסמאות** — רק שמות ושעות.

## ⚠️ מה עדיין לא אומת

**שום דבר כאן לא רץ מול החשבון האמיתי.** ה‑parsing מכוסה בבדיקות, אבל מול
שחזור שנבנה מצילומי מסך — לא מול ה‑HTML האמיתי.

- **הלוגין** — הנתיב `/user/login.php` נלקח מהדפדפן, ושמות השדות נקראים
  מהטופס בזמן ריצה. אמור לעבוד, לא נוסה.
- **`update.php` והפרמטרים שלו** (`ee`, `e`, `y`, `m`) — עדיין ניחוש מפורטל
  העובד. זה הדבר הכי סביר שיישבר.
- **מיקום העמודות** — יתברר רק מול דף אמיתי.

`node verify-setup.js` יגיד לך איזה מהם נשבר. הפלט שלו לא מכיל סודות
(רק "מלא / 8 תווים"), אז אפשר לשתף אותו.

**אם צריך לתקן את `update.php`:** פתח את דף הנוכחות בכרום, F12 ← Network,
והעתק את ה‑URL המלא. שים אותו ב‑`TIMEWATCH_ATTENDANCE_PATH`.
**אל תעתיק את בקשת הלוגין כ‑cURL** — היא מכילה את הסיסמה.

## התקנה

1. `copy timewatch.env.example C:\OfficeSecrets\timewatch.env` ומלא את הסיסמה.
   מספרי העובדים נכנסים ל-`employees.json` — הם לא סודיים.
2. `node verify-setup.js` — עד שהכל ירוק.
3. העתק את קבצי ה‑js לתיקיית הדשבורד וחבר את הראוטים — ראה "ההתראה" למטה.
4. הדבק את `panel.html` בתוך הקטע **"בקרת שרת (פרטי)" 🔒** של `dashboard.html`
   — שם כבר יש הפרדה לתכנים שלך בלבד, כמו שביקשת.
5. פתח את הדשבורד דרך ה‑URL (לא `file://`).

## ההתראה

`notify-presence.js` מפיל בקשת התראה לתור הקבצים של הנוטיפייר. בשרת הדשבורד:

```js
const { registerConnectedEmployees } = require('./connected-employees/server-endpoint');
const { createNotifier } = require('./connected-employees/notify-presence');

registerConnectedEmployees(app, {
  watchNames: ['ברינה'],
  pollSeconds: 120,                                   // התראה גם כשהדשבורד סגור
  notify: createNotifier({ queueDir: 'C:\\notif-requests' }),
});
```

### הצבע

התראות נוכחות מקבלות **סגול** — משפחת צבע שלא בשימוש אצלך, כדי שתזהה מיד
במה מדובר לפני שקראת מילה:

| מצב | צבע | סימן |
|-----|------|------|
| נכנס/ה | `#7c3aed` סגול | 🟣 |
| יצא/ה | `#a78bfa` סגול בהיר | ⚪ |

אדום (תקלה), ירוק (תקין) וכחול (מידע) נשארים למה שהם היום. גם הסימן סגול ולא
ירוק — נקודה ירוקה בתוך התראת נוכחות נקראת כ"הכל תקין", וזו הודעה אחרת.

לשינוי: `createNotifier({ queueDir, colors: { in: '#...', out: '#...' } })`.

### מבנה הבקשה

```json
{ "kind": "presence", "type": "in", "name": "ברינה",
  "title": "נוכחות", "text": "ברינה נכנס/ה — מ־09:04",
  "color": "#7c3aed", "icon": "🟣", "at": "2026-09-02T09:05:00.000Z" }
```

הקובץ נכתב בשם זמני ואז `rename` — פעולה אטומית, כך שהנוטיפייר לא יכול לקרוא
קובץ חצי‑כתוב. UTF-8 מפורש, כדי שהעברית תשרוד.

**אם הנוטיפייר מצפה לשמות שדות אחרים** — `buildNotification` ב‑`notify-presence.js`
הוא המקום היחיד שמכיר את הסכמה שלו. שנה שם ותו לא.
