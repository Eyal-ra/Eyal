# Sync Customer Updates

סקריפט חצי-אוטומטי לסנכרון עדכוני פרטי לקוח בין **Jotform** (טופס הגשה אונליין),
**Powerlink** (CRM בענן) ו**רבגונית** (תוכנת דסקטופ Windows).

## איך זה עובד

1. הלקוח ממלא טופס Jotform עם הפרטים המעודכנים שלו.
2. הסקריפט מושך הגשות חדשות מ-Jotform API.
3. עבור כל הגשה - הסקריפט משווה את הערכים מול Powerlink ורבגונית.
4. אם יש פער, הסקריפט מציג את ההפרשים בטרמינל ומבקש אישור (`y/n/s`).
5. באישור - מעדכן את שתי המערכות:
   - **Powerlink** - דרך REST API
   - **רבגונית** - דרך אוטומציית GUI (`pywinauto`)

## דרישות

- Windows (לאוטומציית רבגונית)
- Python 3.10+
- API key ל-Jotform
- Token ל-Powerlink
- רבגונית מותקנת מקומית

## התקנה

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

copy config.example.yaml config.yaml
# ערוך את config.yaml והכנס את הפרטים שלך
```

## שימוש

```bash
python -m src.main
```

הסקריפט יציג כל הגשה חדשה ויבקש אישור לפני עדכון.

# השוואת רווחיות - שנה מול שנה (Profitability)

רכיב שעונה על שאלה אחת: **האם הרווחיות של המשרד טובה יותר משנה קודמת?**
הוא מקבל ייצוא ממערכת החיובים וממערכת התזרים, ומפיק השוואה בין השנה הנוכחית
לשנה הקודמת - **על אותו חלון תאריכים בדיוק**, כדי שלא תושווה שנה מלאה מול חלקית.

## שימוש

```bash
python -m src.profitability --billing billing.csv --cashflow cashflow.csv --year 2026
```

| דגל | משמעות |
|------|---------|
| `--billing` | קובץ חיובים (CSV/TSV/XLSX) |
| `--cashflow` | קובץ תזרים (CSV/TSV/XLSX) |
| `--year` | השנה הנבדקת (ברירת מחדל: השנה הנוכחית) |
| `--prior-year` | שנת ההשוואה (ברירת מחדל: שנה אחורה) |
| `--until` | סוף חלון ההשוואה `DD/MM`. ברירת מחדל: התאריך האחרון שיש עליו נתונים |
| `--out` | כתיבת הדוח לקובץ במקום למסך |

לקריאת `xlsx` צריך `pip install -r requirements-profitability.txt`. אחרת - שמור כ-CSV.

## אילו עמודות צריך בקבצים

הכותרות מזוהות אוטומטית בעברית ובאנגלית, כולל גרסאות כמו `סכום כולל מע"מ`
או `סכום לפני מע"מ`. הזיהוי מעדיף התאמה מדויקת, ואחרת את הכינוי הארוך ביותר
שמוכל בכותרת.

**קובץ חיובים** - חובה: `תאריך` + `סכום` (או `סכום לפני מע"מ`).
מומלץ: `שם לקוח`, `מע"מ`, `מספר מסמך`.

**קובץ תזרים** - חובה: `תאריך` + `סכום`.
מומלץ: `סוג` (הכנסה/הוצאה), `קטגוריה`, `שם לקוח`.
אין עמודת `סוג`? הכיוון נגזר מסימן הסכום - שלילי הוא הוצאה.

## מה הדוח מראה

- **הכנסות** לפי מועד החיוב (בסיס מצטבר), ללא מע"מ
- **הוצאות** לפי תשלום בפועל, ללא מע"מ
- **רווח תפעולי ושיעור רווח** - זה הקו התחתון של השאלה
- **שיעור גבייה** - כמה מהמחויב באמת נכנס (ברוטו מול ברוטו)
- **לקוחות פעילים, הכנסה ממוצעת ללקוח, לקוחות חדשים ושנשרו**
- **סעיפי הוצאה שגדלו מהר יותר מההכנסות** - שם נשחקת הרווחיות בפועל
- **חמשת הלקוחות הגדולים** ומשקלם בהכנסות

הדוח מסמן במפורש כשהבסיס אינו מאומת: שורות שלא נטענו מדווחות עם מספר השורה
והסיבה, וכשאין עמודת מע"מ נרשם שהסכומים נלקחו כפי שהם. מדד שהוא עצמו אחוז
(שיעור רווח, שיעור גבייה) מוצג בתזוזת נקודות אחוז ולא באחוז-מתוך-אחוז.
